    attach¶

    Reattach your terminal to a running VibePod-managed container.

    Use this to rejoin an agent session after the terminal that started it was closed. Find candidate containers with vp list.

    Usage:

    vp attach [OPTIONS] [container]

    Options:

      container  Container name or ID to attach to (see `vp list`). Omit when
             exactly one managed container is running.

    board¶

    Work through vibepod-board projects with agents

    Usage:

    vp board [OPTIONS] COMMAND [ARGS]...
    work¶

    Claim planned tasks of a board project and let an agent implement each one.

    Each task gets its own branch and worktree. The agent runs headless with the task as its prompt; after an optional --verify command passes, the task moves to Review with its branch. Failed and timed-out tasks go back to Planned (or blocked) with a note.

    Usage:

    vp board work [OPTIONS] {project}

    Options:

      project                       Board project key, such as VP  [required]
  -a, --agent <str>             Agent that implements the tasks  [required]
  --board-url <str>             Board URL; defaults to board.url or
                                VP_BOARD_URL
  --name <str>                  Worker name on the board; defaults to
                                <agent>@<host>
  --label <str>                 Only claim tasks with this label; repeat to
                                require more
  --min-readiness <int range>   Only claim tasks rated at least this ready
                                [1<=x<=10]
  --task <str>                  Work on this one task, such as VP-12, then
                                exit
  --once                        Work on one task, then exit
  --max <int range>             Exit after this many tasks  [x>=1]
  --poll <str>                  When no task is left, wait this long (30s, 5m)
                                and look again instead of exiting
  --repo <path>                 Repository to work in; defaults to the task's
                                local path
  --worktree-dir <path>         Where task worktrees go; defaults to
                                <repo>-worktrees next to the repository
  --base <str>                  Where new branches start; defaults to the
                                repository's current branch
  --branch-template <str>       Branch name from {issue}, {number}, {key} and
                                {project}; tasks without a GitHub issue use
                                {key}, such as vp-12  [default: issue-{issue}]
  --existing <continue|refuse>  When the task's branch or worktree exists:
                                continue or refuse  [default: continue]
  --keep-worktree               Keep worktrees after the hand-over
  --profile <str>               Credential profile to use (see `vp profile
                                list`)
  --provider <str>              Temporary model provider(s) for the agent runs
  --ikwid                       Enable the agent's auto-approval flags
  --timeout <str>               Time limit per task (s/m/h), or 'none'
                                [default: 2h]
  -e, --env <str>               Environment variable KEY=VALUE for the agent
  --network <str>               Additional Docker network for the agent
                                container
  --no-overlay                  Skip the project overlay image
  --verify <str>                Command that must pass in the worktree before
                                the hand-over
  --on-fail <planned|blocked>   Where failed and timed-out tasks go: planned
                                (counts an attempt) or blocked  [default:
                                planned]
  --max-attempts <int range>    Failed attempts before a task is blocked
                                [x>=1]
  --parallel                    Run alongside other workers on the same
                                profile
  --usage-limit-wait <str>      Pause after a usage limit when the agent names
                                no reset time  [default: 30m]

    herdr¶

    Diagnose herdr terminal-multiplexer wiring end to end.

    Run this INSIDE a herdr pane. Without an agent: passive summary of every agent's integration state. With an agent: checks pane env, socket, binary, the injected integration files, the hook trace log, performs a live host-side state report, and (when Docker is available) reproduces the exact in-container herdr call.

    Usage:

    vp doctor herdr [OPTIONS] [agent]

    Options:

      agent            Agent to inspect in depth; omit for an all-agents summary
  --profile <str>  Credential profile to inspect (see `vp profile list`)

    stop¶

    Stop an agent's containers, a specific container, or all managed containers.

    Usage:

    vp stop [OPTIONS] [target]

    Options:

      target       Agent name/shortcut (stops all its containers) or a container
               name or ID from `vp list` (stops just that container).
  -a, --all    Stop all VibePod managed containers
  -f, --force  Force stop

    Options:

      -w, --workspace <path>  Workspace directory  [default: .]

  --no-overlay            Skip the project overlay image

    task¶

    Create and manage headless background agent tasks

    Usage:

    vp task [OPTIONS] COMMAND [ARGS]...
    _watch-timeout¶

    Internal helper launched by vp task create --timeout.

    Usage:

    vp task _watch-timeout [OPTIONS] {task_id} {timeout_seconds}

    Options:

      task_id          Task id to enforce  [required]
  timeout_seconds  Timeout in seconds  [required]
    cancel¶

    Gracefully stop a running task while keeping its record and logs.

    Usage:

    vp task cancel [OPTIONS] {task_id}

    Options:

      task_id  Task id (full or prefix)  [required]
    create¶

    Start an agent task in the background and print its id.

    Usage:

    vp task create [OPTIONS] {agent} {prompt}

    Options:

      agent                   Agent to run headlessly  [required]
  prompt                  Prompt to send to the agent  [required]
  -w, --workspace <path>  Workspace directory  [default: .]
  -e, --env <str>         Environment variable KEY=VALUE
  --name <str>            Custom container name
  --network <str>         Additional Docker network to connect the container
                          to
  --timeout <str>         Maximum task runtime before graceful stop. Use s/m/h
                          suffixes, or 'none' to opt out.  [default: 2h]
  --pull                  Pull latest image before run
  --no-overlay            Skip the project overlay image
  --rebuild-overlay       Force rebuilding the project overlay image
  --no-herdr              Skip herdr terminal-multiplexer wiring
  --ikwid                 I Know What I'm Doing: enable auto-approval flags
                          for supported agents
  --profile <str>         Credential profile to use (see `vp profile list`)
  --provider <str>        Temporary model provider(s) for this launch (see `vp
                          provider list`)
    list¶

    vp task list [OPTIONS]

    Options:

      --agent <str>  Filter by agent name
  --json         Output JSON
  --limit <int>  Max rows to show  [default: 20]
